# 05 复盘

## 实际用时

约 2 小时（数据与费用引擎 30 分钟、循环与工具 40 分钟、测试与续跑 30 分钟、真实模型与文档 20 分钟）。

## 最难的问题

1. **状态而非日志**：评分点在看“步骤依赖与实际状态”。做法是把每次工具调用（含失败）写入流水，
   报告/failure 判断/续跑全部读同一份状态，不依赖模型自述。
2. **续跑语义**：首版把历史失败计入本次重试预算，导致修复后仍直接放弃；
   明确「重试预算按本轮计、历史步骤只作为起点」后，续跑才真正成立。
3. **真实模型的输入缺失行为**：真实模型缺预算时仍去估算、缺截止时被误导性报错带着循环。
   修复不仅靠提示词，还让工具在缺输入时直接返回明确错误，从源头切断错误循环。

## 学习收获

- 预算与时间约束必须由工具计算与复核，模型只能“选”，不能“算”；
- 失败处理的价值在于「保留什么」：成功步骤必须原样保留，失败尝试必须如实记录；
- 续跑 = 状态可重放 + 动作幂等 + 内容哈希识别已成功步骤，三者缺一不可。
